페이지 제출 방법
  1. 실습 저장소를 본인 컴퓨터로 가져오고, GitHub 아이디와 같은 이름의 폴더를 submissions 안에 만듭니다.
  2. 그 폴더에 index.html을 만듭니다. 이미지는 같은 폴더의 images 안에 둡니다.
  3. 본인 폴더의 변경 사항만 GitHub의 main에 올립니다. 다른 사람이 먼저 올렸다면 최신 내용을 받은 뒤 다시 올립니다.
  4. 배포 완료 후 이 화면에서 본인의 GitHub 아이디로 검색합니다. 첫 화면의 목록은 자동으로 갱신됩니다.

본인 폴더 안에서만 수정해 주세요. 첫 화면이나 다른 사람의 폴더를 고칠 필요가 없습니다. 공개되는 페이지에는 연습용 자료를 사용해 주세요.
